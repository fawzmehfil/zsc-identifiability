# Versioned Schemas

The authoritative suite schema is the immutable `EstablishedValidationSuite`
Pydantic model. Unknown fields are rejected. Its canonical instance is
`suites/canonical.json`.

`schemas/commitment-trace-v1.schema.json` defines the runtime interchange record.
Each JSONL line contains only the ego observation, ego action, a partner action
when visible, shared reward, time, visible high-level events, and measurement-only
task-boundary events. Partner identifiers are used for offline estimation but are
not included in any policy tensor.

`schemas/runtime-request-v1.schema.json` defines the content-hashed request sent
to Python 3.10 or 3.9. The isolated runtime verifies the hash and full upstream
commit before importing the environment.

Other compact models are generated by Pydantic and carry `schema_version: 1`:

- partner pool and checkpoint manifests;
- empirical response library;
- trace manifest;
- DRI curve and point;
- matched-population audit;
- diagnostic-option and frontier audit;
- established training manifest;
- policy evaluation and Stage 6 audit manifest.

Schema changes require a new version. Runtime metadata never becomes a learned
observation merely because it appears in an offline manifest.
